# es-canvas デモ ウォークスルー

無音のデモ動画 es1〜5 を、画面で何が起きているかに沿って解説します。5 本それぞれが es-canvas の異なる強みを実演しており、全体で「AI が自制すべき ES ⇔ 直すべき ES」「企業情報あり ⇔ なし」の両極をカバーしています。

**デモサイト**: <https://es-canvas.vercel.app/>(各自の OpenAI キーを入力 = BYOK)

各 ES の本文と検証意図は [test_es_v1.md](test_es_v1.md)、設計の背景は [../README.md](../README.md) を参照。

---

## 凡例 — 画面の見方

**指摘の 3 種類**(中央の本文に、薄い背景色 + 下線で示される):

| 種類 | 意味 |
|---|---|
| **要修正(error)** | 誤字・矛盾など明確な誤り。初回分析で**自動修正**される |
| **推奨(convention)** | ES 慣習に沿った改善提案 |
| **代替案(alternative)** | 好みで選べる言い換え(複数案) |

**4 つの操作**(各指摘カードで選ぶ):**採用** / **編集して採用** / **却下** / **直接編集**。

**逆質問** … AI が「その経験、何を工夫した?」と問い返す。回答すると、その内容を踏まえた提案が出る。

**動的添削** … 一つ採用するたび、残りの指摘が「今の本文」に合わせて作り直される。

> どの操作も **Undo 可能**。数値スコアは一切表示しない(設計判断は README 参照)。

## es1 — 完成度の高いガクチカ × メルカリ
**実演: 企業グラウンディング(根拠つき)+ 動的添削 + 設問適合** ｜ [▶ 動画](https://youtu.be/wxCK3a4TrHA)

**入力**: 英語ディベートサークルで初代女性キャプテンを務め、過去の試合動画 20 本を分析して練習法を設計、出席率 40%→80%、3 名が全国入賞 ── 完成度の高いガクチカ。志望企業「メルカリ」、添削条件「バランス」。

1. **企業調査** — AI がメルカリの採用ページ等を調べ、価値観(Go Bold / All for One / Be a Pro / Move Fast)と採用基準を**引用元 URL つき**で整理する。
2. **初回分析** — 誤字はゼロ(完成度が高い証拠)。指摘は 5 件に**自制**され、過剰に出さない。注目は締めの指摘 ── 「データに基づく仮説検証」という学びを、メルカリが重視する「根拠を持って前例のないやり方を形にし、周囲を巻き込む(Go Bold)」へ接続するよう提案する。この指摘には**出典**(メルカリ採用ページの該当記述)が付く。思いつきではなく、調べた事実に紐づいた添削。さらに末尾の志望動機文を「設問(ガクチカ)に焦点を戻す締め」へ直す**設問適合**の指摘も出る。
3. **動的添削** — 冒頭に成果を前出しする提案を**採用**すると、残りの指摘が作り直される。例えば課題部分の指摘は、理由が「冒頭で『3 名を全国大会入賞に導いた』と到達点が示されたので、課題側も同じ指標でそろえると変化が伝わる」へ**書き換わる**。AI が全体を見て提案を更新している。
4. **面接質問** — この ES から想定される面接質問 4 件も生成される。

**見どころ**: 完成度が高くても、企業に紐づけてさらに伸ばせる。そして採用すると他の指摘も連動して進化する。

## es2 — 自己 PR(誤字あり)× 企業なし
**実演: 誤字の自動修正 + 逆質問(数字の引き出し)+ 企業情報なしでも動く** ｜ [▶ 動画](https://youtu.be/tAvlU7Zm1_Y)

**入力**: 「私の強みは粘り強さ」TOEIC 900 点・塾講師 3 年。誤字が 2 か所(「取得しまた」「成積」)。志望企業は未入力、添削条件「厳しめ」。

1. **誤字の自動修正** — 初回分析の時点で、明確な誤字(取得しまた→取得しました / 成積→成績)が**自動で修正**される(要修正カテゴリ)。文章の衛生面は機械的に整える。
2. **企業情報なしでも分析** — 企業未入力なので企業要約は無し。それでも ES 分析は通常通り動き、無い企業価値を**捏造しない**。
3. **逆質問 → 定量化** — TOEIC の指摘に AI が逆質問する:「TOEIC 900 点は、何点からどれくらいの期間で到達しましたか?」回答「600 点台から約 1 年で 900 点」を入れると、新しい提案が出る ── 「大学では TOEIC 600 点台から 900 点の取得を目標に約 1 年間英語学習を継続し…」。**回答の数字を取り込んだ定量化提案**であり、捏造ではなくユーザーが入力した事実に基づく。

**見どころ**: AI が足りない情報を聞き返し、回答を添削に織り込む。書いた範囲を超えて強くなる。

## es3 — Coffee Cluster × 三菱商事(個性保護)
**実演: 個性保護 + 企業グラウンディング + 設問適合 + 編集して採用** ｜ [▶ 動画](https://youtu.be/QbB2qVrTcC8)

**入力**: カナダ留学で孤立した留学生 5 人とのコーヒー会を 30 人に育て、正式団体化の打診を断り、卒業後 2 年続いている ── 短文を畳みかける文学的な ES。志望企業「三菱商事」、添削条件「**個性保護**」、自由入力「自分の声を残したい」。

1. **個性の認識** — 総評の preserved_voice_note が、この書き手の語り口を明示認識する:「短い文を重ねて情景と余韻をつくる、断定を恐れず文学寄りの語り口」。整える提案も、この個性を壊さない範囲に留める。
2. **企業グラウンディング** — 「正式化を断る」という判断の言語化を、三菱商事が重視する「経営マインドを持って事業価値向上に主体的に関与」へ**根拠つきで**接続する。
3. **編集して採用** — 困難と打ち手の指摘を、AI 提案そのままではなく**手直しして採用**する(「何度も追い出されたが、毎週末 3 軒のカフェを回りお願いし、受け入れてくれる場所を確保し続けた」)。提案を起点に、自分の言葉で確定できる。
4. **設問適合 re-frame** — 末尾の「三菱商事という看板の重み」(設問=ガクチカから志望動機へ逸れている)を、「人が入れ替わっても続く場をどうつくるか」── 経験から得た視点へ**戻す**。企業名への先走りを解消する。

**見どころ**: 個性を守りながら、企業にも設問にも合わせる。そして提案を手直しして採用できる。

## es4 — 環境 NPO(字数オーバー)× 企業なし
**実演: 字数削減(AI が苦手な「削る」)+ 逆質問** ｜ [▶ 動画](https://youtu.be/KWfKMMPNSfg)

**入力**: 環境系 NPO で廃プラスチック問題に取り組み、若者 100 名アンケートを企画してキャンペーン 150 名参加 ── ただし **462 字で 400 字を超過**。添削条件「バランス」。

1. **削減提案** — 総評が「400 字を超えており、削る優先順位が必要」と明示。指摘は**すべて圧縮提案**で、冗長な導入・動機・きっかけ説明を縮め、行動と成果に字数を回す。採用していくと **400 字以内に収まる**。
2. **逆質問** — アンケートの指摘に AI が逆質問する:「アンケートを企画した際、設問設計や回答回収であなた自身が工夫した点は?」回答(関心度だけでなく行動経験まで把握できる設問・自由記述欄・SNS や大学コミュニティで回収)を入れると、新しい提案が出る ── 「…行動経験や行動しない理由まで把握できる設問と自由記述欄を備えた…学生が利用する SNS や大学コミュニティで回答を集め…」。

**見どころ**: AI が苦手な「削る」を構造的に出す。さらに逆質問で施策の中身を引き出す。

## es5 — テニスサークル(矛盾あり)× 企業なし
**実演: 矛盾検出 + 逆質問×2 を独立して処理** ｜ [▶ 動画](https://youtu.be/a1cHOqUgmXU)

**入力**: テニスサークル代表。「3 年間代表を務めた」と「2 年生の春から 2 年間」が**食い違っている**。40→60→20 人、週 4→週 2 回。添削条件「バランス」。

1. **矛盾検出** — 初回分析で、時系列の矛盾(「3 年間」vs「2 年間」)を**要修正として検出**し、自動修正する(「3 年間」→「2 年間」)。数字や時系列の食い違いを見つける。
2. **逆質問が 2 つ同時に** — 2 つの指摘にそれぞれ逆質問が付く:
   - Q1(人数の指摘):「60 人から 20 人規模に移る際、どんな基準で決めましたか?」
   - Q2(練習の指摘):「練習の『密度』を上げるために、実際にどんなメニュー変更を入れましたか?」
3. **2 つの回答が独立して反映** — Q1 に「参加意欲と継続性を重視」、Q2 に「球数・実戦形式の時間・コート回転率」と別々に回答すると、**それぞれが正しい指摘にだけ反映**される(Q1 → 人数の提案、Q2 → 練習の提案)。回答が混ざらない。

**見どころ**: 矛盾の検出。そして複数の逆質問を取り違えずに、独立して処理する。

## 5 本のまとめ

| ES | 企業 | 主に実演している強み |
|---|---|---|
| es1 ディベート(完成度高) | メルカリ | 企業グラウンディング / 動的添削 / 設問適合 / AI の自制 |
| es2 自己 PR(誤字) | なし | 誤字の自動修正 / 逆質問(定量化)/ 企業なしでも動く・捏造防止 |
| es3 Coffee Cluster(個性) | 三菱商事 | 個性保護 / 企業グラウンディング / 設問適合 / 編集して採用 |
| es4 NPO(字数オーバー) | なし | 字数削減 / 逆質問 |
| es5 テニス(矛盾) | なし | 矛盾検出 / 逆質問×2 の独立処理 |

どの ES でも一貫しているのは ── **AI は選択肢を出すだけ。採用・編集・却下の最終判断は、すべて書き手が握る**。
